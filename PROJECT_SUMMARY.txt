🔧 ROUTES API
═══════════════════════════════════════════════════════════════════════════════

GET  /student
     └─ Affiche la liste de tous les étudiants

GET  /student/{id}/details
     └─ Affiche toutes les notes (S3 + S4) avec moyennes

GET  /student/{id}/details/s3
     └─ Affiche les notes du Semestre 3

GET  /student/{id}/details/s4
GET  /student/{id}/details/s4?option={optionId}
     └─ Affiche les notes du Semestre 4 (avec filtre option)

GET  /student/{id}/edit-notes
     └─ Affiche le formulaire d'édition des notes

POST /student/update-note
     ├─ Parameters: eleve_id, matiere_id, note
     └─ Response: JSON {success: bool, message: string}

📈 RÈGLES DE GESTION
═══════════════════════════════════════════════════════════════════════════════

1. NOTES MAXIMALES
   Pour chaque matière → Garder la note maximale obtenue

2. MATIÈRES OPTIONNELLES
   Pour chaque option → Garder la meilleure note

3. ABSENCES
   Absence → Note = 0 (inclue dans la moyenne)

4. OPTIONS
   ├─ Concernent uniquement S4
   ├─ Un étudiant peut avoir plusieurs options
   └─ L'affichage S4 filtre par option

5. MOYENNE PONDÉRÉE
   Moyenne = (∑ Note × Crédit) / ∑ Crédit
